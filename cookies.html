Cookie & Storage Notice

Last updated: 12 November 2026

This website uses essential browser storage for core functionality. It does not include advertising or cross-site tracking cookies in this build.

Essential browser storage

The website uses browser local storage to remember your cookie preference and, when you begin an enquiry, keep a random session identifier so the conversation can be refreshed in the same browser. These values are necessary for the corresponding features to work.

Your choice

The first-visit notice lets you accept the notice or continue with essential storage only. Both options keep essential website functions available. Clearing this site's browser data may remove your preference and the local conversation session identifier.

Application records

Chat messages and community requests are stored in the website's connected database. This is application data and is different from browser cookies or local storage.
